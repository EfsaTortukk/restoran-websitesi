# 🍽️ Restoran Web Sitesi

Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş basit bir restoran web sitesidir. Ana sayfa ve rezervasyon sayfası olmak üzere iki temel sayfa içerir.

## 📄 Sayfalar

- `index.html`: Ana sayfa
- `rezervasyon.html`: Rezervasyon formu

## 🎨 Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## 🖼️ Görseller

- `hamburger-menu.jpg`
- `yemek1.jpg`

## 🚀 Nasıl Çalıştırılır

1. Projeyi klonlayın:
```
git clone https://github.com/EfsaTortukk/restoran-websitesi.git
```

2. `index.html` dosyasını bir tarayıcıda açın.
